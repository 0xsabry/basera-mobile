# 03 — Expo & Mobile Development

**Duration: 2 minutes**

## Scope

- The stack: Expo SDK 58, React Native 0.88, React 19, TypeScript,
  expo-router file-based navigation.
- Android integration: bare workflow (committed `android/` project), package
  `me.auramarketing.basera`, native version stamps in Gradle.
- App lifecycle: startup sequence, providers, permissions, deep-link scheme
  `basera`.
- Builds and updates: EAS build profiles, the preview/production channel
  split, OTA updates with an in-app release-notes source of truth, and the
  release guard that blocks unsafe publishes.

## Out of scope

Feature internals (04–10) and backend deployment (10). This section is the
platform the features run on.
