# 02 — UI/UX

**Duration: 2 minutes**

## Scope

- Screens and navigation: five tabs plus the standalone flows (detect, read,
  voice, alerts, places, updates, onboarding, guardian auth, voice settings).
- The design system: one shared component library, one token set, one visual
  identity (olive palette), light/dark/high-contrast themes.
- Accessibility as a design constraint, not an add-on: TalkBack-first,
  labelled controls, ≥48dp touch targets, content capped at 600dp and
  centered, live-region feedback.
- Localization: full Arabic + English, RTL layout, MSA UI copy guarded by
  automated tests.

## Out of scope

What each feature *does* internally — that is sections 04–10. This section
covers how everything looks, feels, and is operated without sight.
