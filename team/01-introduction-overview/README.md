# 01 — Introduction & Overview

**Duration: 2 minutes**

## Scope

- The problem: blind and visually impaired users need to know what is around
  them, read printed text, and stay connected to family — without sighted help
  at every step.
- The objective: BASERA (بصيرة) — an accessible AI mobile app that describes
  the surroundings, reads text aloud, warns about nearby obstacles, and lets
  family members follow up with the user's explicit consent.
- Target users: blind and visually impaired Arabic and English speakers,
  TalkBack-first.
- The feature set at a high level, the overall architecture, and how a user
  request flows through the app end to end.

## Out of scope

Implementation detail of any single feature — each has its own section
(02–10). This section frames the whole project and hands over cleanly.
